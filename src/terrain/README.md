# terrain/

Seamless 4 km tiles of walkable terrain from the 0.1° PaleoDEM, with each 0.1° cell's mean held to its source value. Runs in a Web Worker. Design: [`PSEUDOCODE.md`](PSEUDOCODE.md) (status and amendments at the top).

| File | What it does |
|---|---|
| `tilegrid.ts` | Fixed global tile grid: rows 4 km tall, an integer number of ~4 km columns per row, so a row closes exactly at ±180°. `tileIdFor`, `tileBounds`, `ring` (3 × 3). |
| `noise.ts` | Seeded improved-Perlin noise; zero-mean fBm and ridged sums; FNV-1a `hash32`. |
| `surface.ts` | The global surface for one slice: `H = S + D + r_c·ψ_c` (below). `sample(lat, lon)` returns H, Hsmooth, the generated part, class, strength and provenance flags. |
| `tile.ts` | `generateTile(surface, id, step)` → heights, Hsmooth, flags, strength, class, normals. `generateFarField` → Hsmooth on a metric lattice for the horizon. |
| `service.ts` | `TerrainService`: a DataStore plus one Surface per slice (LRU 2); runs tile / far-field / inspect requests one at a time. |
| `worker.ts`, `client.ts` | The Web Worker and its main-thread handle (`TerrainClient`, promises, transferable buffers, progress). Falls back to running inline where module workers are unavailable. |

## The surface

- **S:** Catmull-Rom interpolation of the 0.1° nodes (with its analytic gradient for slope).
- **D:** zero-mean noise in global coordinates (fBm; ridged in orogens; domain-warped in lowlands and orogens), amplitude by terrain class (abyssal 20 m … orogen 600 m), damped within 30 m of sea level. Seeded per slice, never per tile.
- **r_c·ψ_c:** per-cell correction. `ψ = 900·(s(1−s))²·(t(1−t))²` has mean 1 over the cell and is zero, with zero slope, on its edges, so `r_c = source − mean(S + D)` makes each cell's mean exact without touching its neighbours.
- **Hsmooth = S + r'_c·ψ_c** (with `r'_c = source − mean(S)`): the same surface without invented detail. `generated = H − Hsmooth`.

Provenance per vertex: `DATA_SURFACE` always; `GENERATED_RELIEF` where |generated| > 2 m; `GENERATED_COAST` where detail moved the point across 0 m. Strength = |generated| / local amplitude, mapped to data / inferred / generated by `provenance/flags.ts`.

## Tests (`terrain.test.ts`, on a synthetic DEM and, if present, the real data)

Tile-grid round trip and antimeridian wrap; E/W seams identical; N/S seam gap < 0.5 m; antimeridian continuity; determinism (also with cold caches); mean preservation < 1 m per cell on an independent offset 96 × 96 lattice, for a lowland and the 150 Ma global maximum (~3 km); land/sea agreement; no NaN; zero-mean noise; serialised worker requests. Benchmark (Node, one core): a full 513² tile in ~0.4–0.7 s, a 129² ring tile in ~0.08 s.
